# 🎬 YouTube Production Assistant (Powered by Google Gemini)

Инструмент-помощник для создания длинных роликов (15–30 минут) на YouTube в нишах с высоким доходом и зеленой монетизацией (тру-крайм, детективные расследования, разборы техно-катастроф, инженерные проекты).

---

## ⚡ Что делает этот проект:

Проект автоматизирует рутину создания видеороликов, разделяя производство на 3 простых шага:

### 1. Написание сильного режиссерского сценария (Google Gemini)
- Принимает ваши сырые материалы (статьи, заметки, факты, ссылки).
- Рассчитывает хронометраж (10, 15, 20 или 30 минут) и объем слов при дикторском темпе ~135 слов/мин.
- **Формула зеленой монетизации YouTube**: строит первые 30 секунд (хук) на интриге и детективном парадоксе, исключая шок-слова («убийство», «кровь»), сохраняя монетизацию.
- Расставляет **микро-клиффхэнгеры каждые 3–4 минуты** перед рекламными паузами mid-rolls для удержания зрителя выше 45%.
- Форматирует текст в режиссерскую таблицу (Тайминг | Видеоряд и звуки | Текст диктора с паузами `[Пауза — Х сек]` и смысловыми ударениями **жирным шрифтом**).

### 2. Формирование промптов для Nano Banana, Kling и Midjourney
- Анализирует сценарий и делит его на сцены.
- Генерирует **русские промпты для Nano Banana** (не нужно переводить, можно сразу вставлять в бот или интерфейс).
- Создает кинематографичные английские промпты для Midjourney v6 и Flux.1 с соотношением сторон 16:9 (`--ar 16:9`).
- Формирует **Motion Prompts** (команды движения камеры) для превращения картинок в 5-секундные видеоролики в **Kling AI**, **Runway Gen-3**, **Luma Dream Machine**.
- Создает идеи и промпты для кликабельной **обложки YouTube (Thumbnail)** с высоким CTR.

### 3. Нейросетевая озвучка дикторским голосом (TTS в MP3)
- Автоматически очищает сценарий от режиссерских меток (удаляет скобки с эмоциями, преобразует метки пауз в естественные дыхательные паузы).
- Озвучивает текст студийным нейросетевым голосом (`ru-RU-DmitryNeural` — глубокий мужской голос для расследований, `ru-RU-SvetlanaNeural` — женский голос).
- **Работает бесплатно и без ограничений** — не тратит токены и не требует платных подписок.
- Позволяет прослушать аудио прямо в браузере и скачать MP3-файл.

## 🚀 Как запустить

### 1. Добавьте API ключ Gemini
В корне проекта создайте файл `.env`:
```env
GEMINI_API_KEY=AIzaSy_ваш_ключ_из_Google_AI_Studio
```
*(Получить ключ бесплатно: [https://aistudio.google.com/](https://aistudio.google.com/))*.

### 2. Запустите Web UI в браузере (Рекомендуется)
```bash
.venv\Scripts\streamlit run web_ui.py
```
В браузере откроется окно студии: `http://localhost:8501`.

### 3. Либо запустите консольный ассистент
```bash
.venv\Scripts\python main.py
```
